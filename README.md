# 🌿 Landscape Website

A modern and responsive **landscaping business website** built using **HTML, CSS, and JavaScript**.  
This project showcases a clean landing page design for landscaping services, including service sections, testimonials, workflow explanation, and contact options.

The website focuses on a **simple UI, responsive layout, and smooth user experience** suitable for service-based businesses.

## 📌 Project Overview

This project represents a **landing page for a landscaping company** where users can explore services, understand the company’s workflow, and easily get in touch.

The layout includes:

- Hero section introducing the business
- Service showcase (Artificial Turf, Masonry, Custom Landscape)
- Client testimonials
- Step-by-step working process
- Contact and call-to-action buttons
- Mobile-friendly navigation menu

The design emphasizes **clarity, modern UI elements, and conversion-focused layout**.
